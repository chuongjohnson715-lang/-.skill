# data-viz-experiment-report

> 基于原版实验报告模板，用 Python + Matplotlib/numpy 完成《数据可视化》课程实验并生成"原版复刻、零 AI 痕迹"的 docx 报告。

一个为 [WorkBuddy](https://www.workbuddy.cn) Agent 平台设计的 Skill。它不是"参考常见格式重新排版"，而是以用户提供的原版实验报告模板/样例作为**版式唯一基准**，在不改变原版结构的前提下替换内容——封面、字体字号、编号体系、固定框、页眉页脚全部保持原样，任何无法确认的格式都不得自行发挥。

## 核心原则

**模板优先、原版复刻、零 AI 痕迹。**

## 适用场景

- 用户给出实验题目或数据集，要求用 Matplotlib/Python 绘制图表（折线/柱状/散点/饼图/词云等）
- 用户要求完成一份《数据可视化》课程实验报告（docx）
- 用户希望沉淀绘图知识点与标准操作流程（SOP）

触发示例：「帮我做这个数据可视化实验报告」「用 matplotlib 画这张表然后写报告」「这是某城市月均温数据，画个折线图并分析」

## 工作流程（SOP 摘要）

| 步骤 | 要点 |
| --- | --- |
| 1 解析需求 | 必须先读原版模板 docx；正文栏位先判「替换 vs 追加」——含老师任务书原文的栏位**保留原文、末尾追加**，不得整段替换 |
| 2 环境检查 | 复用受管 Python 环境；中文字体 `SimHei` + `unicode_minus=False`；无界面用 `Agg` |
| 2.5 字段口径核查 | 先查分布再使用（如豆瓣 `release_date` 是"最近一次上映"会覆盖首映年份，经典影片会得出错误年代结论） |
| 3–4 数据与绘图 | 数值全部由脚本从真实数据算出（`load_facts()`），不手写进正文；脚本存 `code/` 并实际运行通过 |
| 5 运行与校验 | 回读图片确认中文/布局；词云调参专项（max_words/margin/min_font_size） |
| 5.5 docx 版式校验 | 本机无 Word 时用「字节比对 + 结构校验」：未改动部件逐条 md5 比对 + 图片溯源 + AI 关键词 XML 扫描 |
| 6–7 沉淀与生成 | 复制原版 docx 后在原段落/表格/文本框位置替换内容；图片与源码强制「图在上、代码紧随图下」（仅原版有源码栏目时） |
| 7.5 最终校验 | 重新打开生成文件比对页面/边框/字体/图片位置 + 全文 AI 痕迹扫描，不合格不交付 |
| 8 交付 | 报告 docx + 知识点SOP + code/images；封面个人信息**留空不代填**；用户要求极简时只交付报告 |

## 内置质量检查清单

- **A. AI 痕迹检查**：正文/页眉页脚/封面/文本框不得出现"AI生成"等字样，无 AI 水印与生成说明
- **B. 原版模板一致性**：页面/边距/封面/编号/字体/表格/图片位置逐项比对，不新增原版没有的栏目
- **C. 内容与运行结果**：中文不乱码、量化结果真实、图码对应

## 常见坑（精选）

- 不要"重新创建 docx"——直接复制原版模板再替换原有对象内容
- 代码被"顺手美化"（重排缩进/删注释）→ 一律以 `code/` 下实际运行通过的脚本原文为准
- 结论先行、数据后补 → 禁止；所有结论性数字必须先跑出真实值再落笔
- 一、二级标题被自行修改 → 原版文字作为固定字段，不允许润色

## 快速开始

1. 将本仓库放入 WorkBuddy 的 skills 目录（`~/.workbuddy/skills/data-viz-experiment-report/`），或直接用 `@skill:data-viz-experiment-report` 触发；
2. 向 Agent 提供**原版实验报告模板 docx**（必需，没有模板无法保证严格复刻）+ 实验题目/数据；
3. Agent 按 SOP 生成报告，交付前会完成版式校验与 AI 痕迹扫描。

## 环境要求

- Python 3.x + numpy + matplotlib（+ python-docx 用于生成报告）
- 中文绘图需 `SimHei` 字体（Windows 位于 `C:\Windows\Fonts\simhei.ttf`）
- 无图形界面环境使用 `matplotlib.use("Agg")`
